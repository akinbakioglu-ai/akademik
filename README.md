# Geri Sayım

Türkçe, mobil uyumlu ve tek HTML dosyasıyla çalışan özelleştirilebilir geri sayım sayfası.

**Web adresi (GitHub Pages etkinleştirildikten sonra):** https://akinbakioglu-ai.github.io/akademik/geri-sayac/

- `geri-sayac/index.html` dosyasında tüm HTML, CSS ve JavaScript bulunur.
- Tarih, saat ve başlık arayüzden değiştirilebilir.
- Paylaşım bağlantısı hedef anı ISO 8601 biçiminde taşır; farklı saat dilimlerinde doğru çalışır.
- Koyu/açık tema ve tarayıcıda yerel ayar saklama desteklenir.

## GitHub Pages yayını

Bu depoda **Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save** seçin. Ardından sayfayı üstteki adresten açın.
